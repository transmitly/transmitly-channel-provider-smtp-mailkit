# Transmitly.ChannelProvider.Smtp.MailKit

A [Transmitly](https://github.com/transmitly/transmitly) channel provider dispatcher implementation using [MailKit](https://github.com/jstedfast/MailKit).

### Getting started

If you're just starting out with Transmitly, you likely want to be using the [transmitly-channel-provider-smtp](https://github.com/transmitly/transmitly-channel-provider-smtp) package instead.

See the [Transmitly](https://github.com/transmitly/transmitly) project for more details on what a channel provider is and how it can be configured.
